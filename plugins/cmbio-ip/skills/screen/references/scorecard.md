## Patentability

| Dimension | Score | Reason |
|---|---|---|
| **Novelty confidence**: nothing found that discloses this | | |
| **Inventive step**: a skilled person would not have arrived at this obviously | | |
| **Eligibility**: survives subject-matter objections (EPO Art. 52 for computer-implemented methods and Art. 53 for diagnostic/treatment methods; US §101 for algorithms and natural correlations) | | |
| **Enablement**: enough data exists now to support a filing | | |

Computational biology hits eligibility problems more often than novelty problems. A method that is a mathematical step applied to biological data needs a technical effect to survive at the EPO and something more than an abstract idea plus routine steps in the US. If this score is 2 or below, the firm assessment should lead with eligibility rather than prior art.
