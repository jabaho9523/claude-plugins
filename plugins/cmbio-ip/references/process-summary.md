# Cmbio IP process, in one page

Full version lives with the IP owner. This is what a skill needs to know.

## The funnel

| Stage | What | Who | When |
|---|---|---|---|
| 0 | Inventor produces an IDF (via `/cmbio-ip:disclose`) | Inventor | Within 30 days of a technical milestone |
| 1 | First-pass screen (via `/cmbio-ip:screen`, which calls `/ip-legal:invention-intake` if installed) | IP owner | Same week |
| 2 | Review panel scores and routes | Panel | Monthly, 30 minutes |
| 3 | Patent firm assessment | Firm | Batches in February and September |
| 4 | Filing, trade secret register entry, defensive publication, or no action | Per decision | |
| 5 | Annual R&D documentation pack to the auditor | IP owner + finance | January |

## The four routes

| Route | Use when |
|---|---|
| Patent | A competitor using it would be detectable from outside, and it sits on or near something Cmbio sells |
| Trade secret | Valuable but undetectable in use (pipeline internals, parameters, reference data, scoring logic) |
| Defensive publication | Not worth owning, but damaging if a competitor patented it |
| No action | Neither novel enough nor commercially relevant. The IDF is still kept for tax documentation. |

## The routing grid

|  | Low detectability | High detectability |
|---|---|---|
| High commercial relevance | Trade secret | Patent candidate |
| Low commercial relevance | No action | Defensive publication |

## Why the IDF has a tax section

Danish R&D deductions require documentation that the work was novel, involved a creative element, and had technical or scientific uncertainty at the outset (the Frascati criteria). The IDF captures this contemporaneously so it does not have to be reconstructed later. A disclosure that never becomes a patent is still valuable for this purpose.

## Three rules

1. No external disclosure before a route decision. Europe has no grace period.
2. Check who owns it. Cmbio is a CRO and most sponsor agreements assign foreground results to the sponsor. Cmbio's inventions must live in background IP and improvements.
3. A trade secret only exists if Cmbio can show it took reasonable steps to keep it secret. Register entries and access control are not optional.
